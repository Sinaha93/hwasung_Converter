공식 캡처 출처: https://docs.github.com/en/get-started/using-github/hello-world

공식 문서 캡처와 우리 예제 실측 캡처를 구분합니다. 로그인 없이 읽을 수 있는 영역을 캡처했으므로 실제 저장소 생성·PR 제출·검토·Merge 버튼은 로그인한 본인 계정 및 권한에 따라 달라집니다. 강사의 자체 점검 기록은 다른 사람의 승인으로 설명하지 않습니다.

2026-10-07 주변 문맥 보강: 핵심 버튼만 자른 캡처를 저장소 탐색 탭·Issue/PR 제목·본문·주변 메뉴를 함께 보여주는 1280×850 실제 화면으로 교체했습니다. 공식 문서 캡처도 앞뒤 설명과 문서 메뉴를 포함합니다. 세부 글자는 슬라이드의 크게 보기에서 확인합니다. 공개 예제의 작성자 표시는 실제 공개 GitHub 계정이며 회사·직원 자료가 아닙니다.

- docs-collaborator: GitHub 공식 개인 저장소 초대 안내의 Settings 캡처와 앞뒤 초대 단계. https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/repository-access-and-collaboration/inviting-collaborators-to-a-personal-repository . 실제 조원 초대·수락 화면이나 완료 증거로 설명하지 않습니다.

- 17_github-login: https://github.com/login 실제 입력 전 로그인 화면. Sign in·Continue with Google·Create an account를 포함하며 계정·비밀번호는 입력하지 않았습니다. 가입 페이지는 자동 접근 제한으로 캡처하지 않았으며 신규 가입 카드의 출처는 https://docs.github.com/en/account-and-profile/how-tos/account-management/creating-an-account-on-github 입니다.
