# 작업 규칙

- 가상 자료만 사용한다.
- 작업 전 README.md와 design.md를 읽는다.
- main을 직접 수정하지 않고 작업 branch를 만든다.
- 요청한 기능과 담당 파일만 변경한다. 다른 사람의 변경을 되돌리지 않는다.
- data.js는 공통 입력이다. 새 요청이 없으면 바꾸지 않는다.
- 미완료 필터는 app.js 담당, CSV 저장은 export.js 담당이다.
- index.html은 공통 진입점이다. 담당자와 합의한 뒤 바꾼다.
- 완료 전 전체 4건·미완료 3건·원본 보존·CSV 저장을 확인한다.
- PR에는 목적, 변경 파일, 확인 방법과 현재 한계를 쓴다.
