# 가상 업무 요청 목록 설계

## 목적

요청 담당자가 남은 일을 확인하고 현재 목록을 저장한다.

## 파일과 소유권

| 파일 | 역할 | 담당 |
|---|---|---|
| index.html | 화면·버튼·공통 진입점 | 통합 담당 |
| data.js | 가상 요청 4건 | 공통 입력 담당 |
| app.js | 필터·목록 표시 | 필터 담당 |
| export.js | 현재 목록 CSV 저장 | 저장 담당 |
| README.md | 실행·확인 방법 | 문서 담당 |

## 공통 인터페이스

- window.requests: 원본 배열. id, task, status 세 값.
- window.visibleRequests: 현재 화면 배열. 원본은 보존한다.
- export 버튼은 현재 화면 배열을 읽는다.
- 완료 판단은 status가 완료인지로 정한다.

## 디자인

밝은 배경, 검은 제목, 인디고 버튼. system-ui. 표는 열 제목과 상태를 표시한다.
키보드로 버튼을 누를 수 있고 초점을 표시한다. 결과 건수를 화면에 표시한다.

## 완료 기준

전체 4건 → 미완료 3건 → CSV 3건 → 전체 4건 복원.
이 예제는 로그인, DB, 실제 업무 시스템 연결을 포함하지 않는다.
