# 가상 업무 요청 목록

설치 없이 브라우저에서 여는 공개 교육용 도구입니다. GitHub 협업을 연습합니다. 모든 요청과 상태는 가상 자료입니다.

## 실행

index.html을 브라우저에서 엽니다. 설치나 서버가 필요 없습니다.

## 시작 결과

전체 요청 4건을 보여줍니다. 완료 1건, 미완료 3건입니다.

## 함께 만들 기능

- 미완료 요청만 보기
- 현재 화면의 요청을 CSV로 저장하기

## 수업에서 확인할 순서

Issue → branch → 변경·commit → push → PR → 변경 비교·검토 → merge → main 재실행

이 저장소를 복제해 자기 연습 저장소에서 실습합니다. 이 예시 저장소로 PR을 보내는 것은 필수가 아닙니다.
