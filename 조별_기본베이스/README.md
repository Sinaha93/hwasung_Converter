# 팀 업무요청 관리 · 동시 개발 베이스

3~5명이 각각 독립 업무 영역을 개발합니다. 다섯 영역에 같은 가상 요청4건이 연결돼 있습니다. 업무 기능은 수강생이 구현하며 공통 연결부는 이미 작동합니다.

## 실행

ZIP을 조마다 새 폴더에 풀고 index.html을 브라우저에서 엽니다. 별도 설치 없이 실행합니다. 다섯 영역을 눌러 가상4건과 이력을 확인하세요. smoke.html에서 공통 등록·변경·메모를 확인한 뒤 초기화하고 개발을 시작합니다.

팀_역할과작업.md에서 역할을 정하고 각 modules/영역/TASK.md를 읽습니다. index.html과 core는 수정하지 않고 자기 modules/영역/index.js만 구현합니다. 각 모듈은 이미 등록·연결되어 있고 데이터 변경을 구독해 갱신합니다.

## 준비 완료된 공통 파일

- core/seed.js: 가상 요청4건·시작 이력
- core/store.js: 등록·수정·메모·자동 이력·저장·변경 알림
- core/ui.js: 안전한 DOM·표 도우미·모듈 등록
- core/app.js: 영역 이동·초기화·오류 격리
- core/styles.css: 공통 디자인 토큰
- CONTRACT.md: 데이터와 API 약속

한 모듈의 등록/실행 오류는 해당 영역에 안내하며 다른 영역은 사용할 수 있습니다. 다만 공통 파일은 모든 영역이 사용하므로 변경 전에 합의합니다.

데이터는 각 PC·브라우저에 저장합니다. 조원 PC 실시간 공유 서버는 포함하지 않습니다. GitHub로 코드를 합친 뒤 각 PC에서 통합 결과를 확인합니다. 실제 회사자료·개인정보·기밀·인증정보는 넣지 않습니다.

기존 필터/CSV 예제는 상위 예시레포/start에 보존됩니다. 이 베이스는 modules 구조만 사용합니다.
