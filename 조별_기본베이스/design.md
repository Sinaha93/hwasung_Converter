# 동시 개발 베이스 디자인 기준

기존 교육용 밝은 배경·검은 제목·인디고 강조를 계승합니다. 데이터/API 연결은 CONTRACT.md가 기준입니다.

- 토큰: 배경 #fafaf9, 표면 #fff, 본문 #0a0a0a, 보조 #586174, 강조 #4f46e5, 테두리 #e5e7eb, 오류 #b91c1c.
- 본문 system-ui 18px, 제목32px, 간격24px, 모서리12px, 버튼·입력 최소44px.
- 공통 컴포넌트: 헤더·영역 이동·패널·안내·표·오류. 실제 DOM으로 구성합니다.
- 영역 선택은 aria-pressed, 비선택 패널은 hidden. 키보드 초점 테두리, 알림 role=status.
- 600px 이하에서 패딩16px/제목28px. 이동 버튼 줄바꿈, 표 가로 스크롤, 한국어 keep-all.
- 모션 없음. 데이터 변경 후 모든 영역을 즉시 갱신합니다.
- core/styles.css는 공통 원본. 자기 모듈은 root 안에서 화면을 만들며 다른 영역 스타일·DOM을 변경하지 않습니다.
- 시작 화면은 연결 확인용입니다. 실제 업무 기능은 각 TASK.md에 따라 구현합니다.
