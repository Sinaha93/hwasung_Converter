# C · 현황판

## 먼저 이해할 네 가지

| 질문 | 내 역할에서 할 일 |
|---|---|
| 왜 하나요? | 남은 일과 지연 업무를 한눈에 보기 |
| 지금 무엇을 하나요? | 상태·담당별 건수를 보고 기준일 2026-10-13으로 지연 확인 |
| 성공 확인은? | 가상 4건의 집계가 맞고 REQ-002가 지연에 표시 |
| 다음 행동은? | 처리 상태 변경 뒤 집계가 갱신되는지 확인 |

코드를 설명하기보다 위 행동을 직접 해봅니다. 다른 영역이 아직 없으면 가상 데이터와 공통 연결 확인 페이지로 자기 기능을 확인합니다.


## 맡을 영역

상태/담당별 집계·기준일 선택·미완료 지연 목록

담당 파일은 modules/dashboard/index.js입니다. CONTRACT.md를 읽고 list/subscribe API를 사용합니다. core와 다른 담당 파일은 수정하지 않습니다.

## 단독 완료 확인

4건 집계 → 기준일2026-10-13의 지연 REQ-002 → 처리 변경 후 집계 갱신

다른 영역이 미완성이면 smoke.html로 등록·변경·메모 데이터를 만들어 확인합니다. 시작 연결 확인 화면은 업무 기능 완료가 아닙니다.
