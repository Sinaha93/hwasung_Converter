# E · 보고서

## 먼저 이해할 네 가지

| 질문 | 내 역할에서 할 일 |
|---|---|
| 왜 하나요? | 필요한 요청만 모아 전달할 파일 만들기 |
| 지금 무엇을 하나요? | 등록일 기간·상태를 고르고 미리보기 후 CSV 저장 |
| 성공 확인은? | 화면과 CSV의 내용·건수가 같고 한글이 정상 |
| 다음 행동은? | 처리와 합친 뒤 바뀐 상태로 다시 보고서 확인 |

코드를 설명하기보다 위 행동을 직접 해봅니다. 다른 영역이 아직 없으면 가상 데이터와 공통 연결 확인 페이지로 자기 기능을 확인합니다.


## 맡을 영역

기간/상태별 보고서·미리보기·집계·한글 CSV 저장

담당 파일은 modules/report/index.js입니다. CONTRACT.md를 읽고 list/subscribe API를 사용합니다. core와 다른 담당 파일은 수정하지 않습니다.

## 단독 완료 확인

4건 미리보기 → 조건 좁히기 → CSV 건수 비교 → 빈 결과·쉼표/따옴표/줄바꿈 확인

다른 영역이 미완성이면 smoke.html로 등록·변경·메모 데이터를 만들어 확인합니다. 시작 연결 확인 화면은 업무 기능 완료가 아닙니다.
