# D · 업무 기록

## 먼저 이해할 네 가지

| 질문 | 내 역할에서 할 일 |
|---|---|
| 왜 하나요? | 요청에 남은 변경 기록을 찾기 |
| 지금 무엇을 하나요? | 기간·현재 상태로 좁히고 요청 상세와 변경 항목·시각 보기 |
| 성공 확인은? | 조건에 맞는 기록·상세 표시 · 없는 조건은 안내 |
| 다음 행동은? | 등록·처리와 합친 뒤 새로운 이력을 확인 |

코드를 설명하기보다 위 행동을 직접 해봅니다. 다른 영역이 아직 없으면 가상 데이터와 공통 연결 확인 페이지로 자기 기능을 확인합니다.


## 맡을 영역

이력 목록·상세·기간/상태 조건·빈 결과 안내

담당 파일은 modules/history/index.js입니다. CONTRACT.md를 읽고 history/get/subscribe API를 사용합니다. core와 다른 담당 파일은 수정하지 않습니다.

## 단독 완료 확인

시작 이력 조회 → smoke 실행 후 업무 화면으로 돌아가 새로고침 → 이력 반영 → 없는 조건 안내

다른 영역이 미완성이면 smoke.html로 등록·변경·메모 데이터를 만들어 확인합니다. 시작 연결 확인 화면은 업무 기능 완료가 아닙니다.
