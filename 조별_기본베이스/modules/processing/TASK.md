# B · 업무 처리

## 먼저 이해할 네 가지

| 질문 | 내 역할에서 할 일 |
|---|---|
| 왜 하나요? | 누가 맡고 어디까지 했는지 남기기 |
| 지금 무엇을 하나요? | 가상 요청 하나를 담당 B로 바꾸고 메모를 남긴 뒤 완료 |
| 성공 확인은? | 담당·메모·상태가 저장되고 다시 열어도 유지 |
| 다음 행동은? | 현황과 합쳐 완료 건수가 바뀌는지 확인 |

코드를 설명하기보다 위 행동을 직접 해봅니다. 다른 영역이 아직 없으면 가상 데이터와 공통 연결 확인 페이지로 자기 기능을 확인합니다.

목록·상세 선택·담당/상태 변경·처리 메모·완료 처리
